# Nasdaq-100 M5 retest | Bridge 1.0.26

Adds read-only nas100_probe and an explicit nas100_activate action with exact broker symbol. Accepted aliases must also have USD profit currency and a Nasdaq/US Tech contract description. Existing XAUUSD settings are unchanged by installing this release.

Activation pauses the previous worker, requires all previous intents reconciled and both old/new symbols flat, then switches settings and starts the same M5 BOS/retest engine. A new symbol has a separate persisted setup file. No historical entries, test orders, timer closures or account changes occur.

Sizing uses at most 0.5% equity, capped at the lower of USD 50 and the previous fixed-volume maximum-stop loss. Broker minimum and volume step are respected by rounding down or skipping. Cash sizing requires a USD demo account. Stop cap is four current M5 ATR bounded to 30–300 price points; max spread is 5 price points. TP1 remains 1R and at most one position per symbol.

Run python -m unittest discover -s bridge/market_structure_m5/tests -v. Offline tests cover gold compatibility, Nasdaq identity, risk ceilings, volume minimum, demo/account restrictions, causal M5 retests, single-position and restart protections. Installation requires a signature under the existing installed key; no trust root is replaced.
